# نتيجة الثانوية العامة

موقع static جاهز للرفع على GitHub Pages.

## الملفات

- `index.html`: صفحة الاستعلام.
- `style.css`: شكل الصفحة.
- `script.js`: البحث في ملفات JSON.
- `data/shards/*.json`: بيانات النتائج مقسمة حسب أول 3 أرقام من رقم الجلوس.

## التشغيل

افتح `index.html` محليًا أو ارفع محتويات المجلد على GitHub Pages.
